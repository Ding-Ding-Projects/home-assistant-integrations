Hello, package.

The smallest thing that installs. One integration, one sensor, and the sensor says which version of the package it came from. Start here if you want to build your own.

hello_package-1.0.0.hapkg
01 / what it does

It proves the pipeline works

If this package installs, updates and shows its sensor, then packaging, checksums, the Marketplace drop and the update check are all working on your system.

02 / inside

A ZIP with a manifest

03 / setup

Add it, press Submit

  1. Settings, Devices and services, Add integration.
  2. Choose Hello package and press Submit.
04 / entities

One sensor

sensor.package_demo    1.0.0

Named Package demo. Its state is the version of the installed package.

05 / options

One field

Configure lets you rename the sensor. That is all.

06 / install

Drag, drop, confirm

Download the file, open the Marketplace page in Home Assistant, and drop it anywhere on the page. Check the source and the verified checksums, confirm, then restart when asked. On a phone, use Install from a package file.
