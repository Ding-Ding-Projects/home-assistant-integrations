i. what it does

One sensor per date, counting down

Each named date becomes a sensor holding the number of days left, with the next occurrence as an attribute. Yearly dates roll forward by themselves the day after they pass; one-off dates stop at zero.

ii. setup

Add it, then add dates

  1. Settings, Devices and services, Add integration, Countdown.
  2. Type a name and pick the date.
  3. Choose Every year or Just once.
  4. Repeat for each date you want to watch.
iii. entities created

Two per date

  • sensor.mums_birthday_days_untilWhole days left. Example: 9
  • sensor.mums_birthday_next_dateThe next occurrence. Example: 3 December 2026
iv. options

Change or remove a date

Open Configure on the integration to rename a date, move it, switch between yearly and one-off, or delete it. Sensors keep their history when you rename.

v. install

Drag, drop, confirm

Download the package, open the Marketplace page in Home Assistant and drop the file anywhere on it. Check the source and the verified checksums, confirm, and restart when asked. On a phone, use Install from a package file.
