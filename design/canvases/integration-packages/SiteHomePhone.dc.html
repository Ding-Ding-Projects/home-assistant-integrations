Installing takes three steps

  1. 01Download the fileEvery integration is one .hapkg file, built and published from the repository by its release workflow.
  2. 02Drop it on the MarketplaceDrag the file anywhere onto the Marketplace page, or use Install from a package file on a phone or with a keyboard.
  3. 03Confirm and restartHome Assistant checks every file against its checksum, shows where the package came from, and asks before adding it.
