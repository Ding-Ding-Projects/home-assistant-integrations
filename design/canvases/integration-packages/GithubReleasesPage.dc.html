Know when it ships.

Watch any public GitHub repository. Home Assistant holds the latest release tag and when it was published, ready for a dashboard or an automation.

what it does

One device per repository

For each repository you list, the integration asks GitHub for the latest published release and stores its tag and publish time. Pre-releases and drafts are ignored. No account or token is needed because only public repositories are supported.

setup

Type owner/name

  1. Settings, Devices and services, Add integration, GitHub releases.
  2. Enter a repository as owner/name, for example home-assistant/core.
  3. Add as many as you like; each is checked on the same schedule.
entities created

Two sensors each

sensor.home_assistant_core_latest_releaseThe release tag. Example: 2026.11.3
sensor.home_assistant_core_publishedWhen it was published. Example: 20 Nov 2026, 19:42
options

List and schedule

Configure lets you add or remove repositories and choose how often to check: every hour, every 6 hours (the default), or once a day. Unauthenticated GitHub requests are rate limited, so a long list is best checked less often.

install

Drop the file on the Marketplace

Download the package, open the Marketplace page in Home Assistant, and drag the file anywhere onto it. Check the source and the verified checksums, confirm, then restart when asked. On a phone, use Install from a package file.
