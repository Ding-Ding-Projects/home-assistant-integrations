What it does

You describe each stream once: which weekday it goes out, and whether that is every week or every N weeks counted from a date you know was a collection day.

From that it works out the next collection date for every stream, how many days away it is, and one simple flag, Put the bins out tonight, that turns on the evening before any collection.

Setup

  1. Go to Settings, Devices and services, Add integration, and choose Bin day.
  2. Name a stream, pick its weekday, and choose weekly or every N weeks.
  3. For every N weeks, pick one date that was a collection day.
  4. Add more streams the same way. Each one becomes a device.

Options

Change any stream later from the integration's Configure button: weekday, interval in weeks, the reference date, and the hour from which Put the bins out tonight turns on (18:00 by default).

Install

Download the package above, open the Marketplace page in Home Assistant, and drag the file anywhere onto it. Check the source and the verified checksums, confirm, then restart when asked. On a phone, use Install from a package file instead.
