Edge TTS / text to speech

Give your home a voice.

Edge TTS lets Home Assistant read any text aloud through your speakers, using the online read-aloud voices from Microsoft Edge. More than 400 neural voices, many languages, no account and no key.

Channel 01
What it does

Text in, speech out

It adds a text-to-speech engine to Home Assistant. Anything that can speak, such as the Text to speech dialog on a media player, an automation, or a voice assistant, can use it to turn a sentence into audio and play it on a speaker.

The text is sent to Microsoft's online read-aloud service to be turned into audio, so Home Assistant needs an internet connection when it speaks. No sign-in is involved.

Channel 02
Setup

Pick a voice, and it is ready

  1. Settings, Devices and services, Add integration, Edge TTS.
  2. Choose a language, then a default voice from the list. You can search by name.
  3. Press Submit. The speech entity appears straight away.
Channel 03
Entities

One entity, three ways to use it

tts.edge_ttsMedia dialogOpen a media player, choose Text to speech, pick Edge TTS and type a message.
tts.speakAutomationsCall the speak action with a message and the speaker to play it on.
Assist pipelineVoice assistantsSelect Edge TTS as the text-to-speech step of an assistant.
Channel 04
Options

Tune how it sounds

voice400+ voicesThe default voice, changeable at any time.
rate-50% to +100%How fast it speaks.
pitch-50Hz to +50HzHow high or low it sounds.
volumeVolumeLouder or quieter than the voice's normal level.
output formatAudio formatThe audio quality sent to the speaker.

A single call can override the voice, rate and pitch without changing the defaults:

action: tts.speak
target:
  entity_id: tts.edge_tts
data:
  media_player_entity_id: media_player.kitchen
  message: "The washing machine has finished."
  options:
    voice: en-GB-SoniaNeural
    rate: "+10%"
    pitch: "-5Hz"
Channel 05
Install

Drop the file on the Marketplace

Download the package, open the Marketplace page in Home Assistant, and drag the file anywhere onto it. Check the source and the verified checksums, confirm, then restart when asked. On a phone, use Install from a package file.
